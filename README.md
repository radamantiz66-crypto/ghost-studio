# Ghost Studio

Constructor de copy de venta para prendas del bazar. Subes fotos de la prenda y sus datos (marca, talla, precio, estado); Gemini la identifica, busca información en Google y escribe un copy AIDA de 100 a 150 palabras con emojis y hashtags, listo para copiar y pegar.

**Uso:** abre la página publicada, toca "Configurar API" y pega tu clave de Google AI Studio. La clave se guarda solo en tu navegador; no está en este repositorio.
